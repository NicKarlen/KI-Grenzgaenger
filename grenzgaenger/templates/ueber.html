Über das Projekt

Ein unabhängiger Wegweiser, kein Verkaufsportal

Der KI-Grenzgänger hilft Schweizer KMU bei einer einfachen Frage: Welche KI-Tools darf ich mit meinen Firmendaten nutzen – und wo landen diese Daten?

Wer steht dahinter?

  • Ein unabhängiges Projekt. Kein Anbieter bezahlt für die Aufnahme oder für eine Bewertung.
  • Keine Werbung, keine Affiliate-Links, kein Tracking. Die Website lädt keine Schriften oder Skripte von Dritten.
  • Der Quellcode und alle Daten sind öffentlich auf GitHub einsehbar{% if repo_url %}: zum Repository{% endif %}. Jede Änderung ist dort nachvollziehbar.

Wie bewertet wird

Jedes Tool erhält zwei Ampeln: eine für Personendaten und eine für das Berufsgeheimnis. Wo die Kanzlei VISCHER ein Tool rechtlich bewertet hat, übernehmen wir diese Bewertung («VISCHER-geprüft»). Alle anderen Ampeln sind eine eigene Einordnung auf Basis öffentlicher Anbieterangaben. Jeder Steckbrief nennt seine Quellen.
